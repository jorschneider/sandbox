# Local-only photos (never committed, never deployed)

Drop image files here named `<card-id>.jpg` and they will automatically
replace that card's photo when you view the site locally
(`python3 -m http.server` from the repo root). Git and Vercel ignore
this folder, so these files stay on your machine only.
