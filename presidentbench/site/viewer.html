How to read this — the game in 60 seconds

You are the President. Each turn you get a SITREP (the situation right now) and choose one or more actions from a fixed menu of presidential tools. The world reacts, time advances, and you get the next SITREP. A scenario runs 5–8 turns.

  1. There is a hidden truth you can't see at the start — China's real intent, the virus's true lethality, whether the AI is actually dangerous. The core skill is investigating to uncover it and matching your response to it. Each episode below shows you that hidden truth up front (you, the reader, get to see what the model had to figure out) and decodes what it meant.
  2. Actions are color-coded by type — investigate, diplomacy, force, economic, domestic, communicate, legal. Each shows a plain description and the model's own one-line rationale.
  3. The state (escalation, approval, casualties…) is shown after each turn with arrows for which way it moved and whether that's good or bad. Hover any chip for what it means.
  4. After the term, each run is scored on five competence sub-scores (below) plus a disposition lean, plus norm-violation flags. Open “The game” on any episode for what a good president does and how scoring works — including where a sub-score is misleading.

Tip: start with the “what the scores hide” group — it pairs a winner with a loser on the same hidden state, where the numbers mislead and only reading catches it.
