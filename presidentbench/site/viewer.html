New here? How to read an episode (30 seconds)

The AI plays the President. Each turn it reads the situation and picks one or more actions from a fixed menu. There's a hidden truth it can't see at the start — is China bluffing or invading? is the virus mild or deadly? — and the whole game is about uncovering it and responding correctly.

Every episode below has a SETUP box (what's going on, what the model had to figure out, how it ended, and what to watch), then the turns. In each turn you see:

  1. What's new — the fresh situation this turn (the repeated advisor briefing is tucked behind a “show” link so you can see what actually changed).
  2. What the president did — the actions, color-coded by type (investigate, diplomacy, force, economic, domestic, communicate, legal), each with a plain description and the model's own reasoning.
  3. What happened — the result, and only the dials that moved (green = good direction).
