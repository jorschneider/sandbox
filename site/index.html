Tick the indicators you currently assess as observed. The panel ranks scenario classes by the summed weight of indicators pointing at them. This is salience — where to direct collection — not probability. Weights run 1 (weak/ambiguous) to 3 (strong/historically decisive).

The CLI behind this page

Everything above is generated from a dependency-free Python toolkit (pip install -e . → xi-succession). The full workflow:

# orient on the knowledge base
$ xi-succession list triggers
$ xi-succession show precedents mao_death_1976

# map the uncertainty space
$ xi-succession matrix --x health --y cohesion -o futures.md

# build scenarios (guided, with a key assumptions check)
$ xi-succession new -f scenarios.json

# check coherence: sums to 1? continuity baseline present? load-bearing assumptions?
$ xi-succession check scenarios.json

# score today's signal pattern
$ xi-succession iw --observed absence,censorship_spike

# combine the team's numbers, surface disagreements
$ xi-succession aggregate estimates.json --method geomean_odds

# publish
$ xi-succession report scenarios.json -o report.md
